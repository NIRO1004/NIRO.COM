SHOES TO GO

Sobre el proyecto

Shoes To Go es un proyecto web desarrollado como parte de los proyectos que forman parte de mi portafolio.

Objetivo

Desarrollar una página web para presentar una propuesta relacionada con una tienda de calzado.

Tecnologías

HTML
CSS
JavaScript

Funcionalidades principales

  • Página web de Shoes To Go
  • Interfaz para una tienda de calzado
  • Navegación entre secciones
  • Diseño web personalizado

Lo que aprendí

  • Estructuración de páginas HTML
  • Diseño mediante CSS
  • Uso de JavaScript
  • Organización de un proyecto web
