PORTAFOLIO WEB

Sobre el proyecto

Este proyecto corresponde a mi portafolio web personal, desarrollado para reunir en un solo sitio mis proyectos, información personal, fotografía, experiencia y diferentes formas de contacto.

El sitio funciona como una presentación personal y como un espacio donde puedo mostrar los diferentes trabajos y proyectos que he desarrollado durante mi formación.

Objetivo

Crear una plataforma personal para mostrar mis proyectos, habilidades y experiencia como estudiante y desarrollador, manteniendo toda la información organizada y accesible desde un solo sitio web.
